# CompAir

CompAir это бесконтактное управление компьютером через веб-камеру. MediaPipe находит 21 точку кисти, модуль признаков определяет положение и позу пальцев, а контроллер превращает жесты в движение курсора, клики, перетаскивание, прокрутку и нажатия клавиш.

## Возможности

* Перемещение курсора указательным пальцем или основанием указательного пальца.
* Левый клик коротким щипком большого и указательного пальцев.
* Перетаскивание удержанием щипка.
* Правый клик щипком большого и среднего пальцев.
* Прокрутка колёсиком жестом «два пальца».
* Пауза и остановка курсора кулаком.
* Режим презентации со сменой слайдов взмахом открытой ладони.
* Игровой режим с прыжком и приседанием.
* Включение и выключение управления жестами без фокуса на окне программы.
* Экранная панель с состоянием жестов, FPS и временем распознавания.
* Плавное движение курсора в отдельном потоке с частотой выше, чем у камеры.

## Как это работает

```text
frame
  -> HandTracker        поиск 21 точки кисти
  -> GesturePipeline    признаки, роли рук, сглаживание, жесты
      -> PointerMachine курсор, клики, перетаскивание
      -> ScrollEngine   прокрутка
  -> Controller         мышь и клавиатура
  -> Overlay            панель и подсказки поверх видео
```

Основной цикл находится в `main.py`. Он получает кадр, передаёт его в конвейер, применяет результат к системе и рисует интерфейс.

## Стек

* Python 3.10+
* OpenCV
* MediaPipe Tasks
* NumPy
* PyAutoGUI

## Требования

* Веб-камера или IP камера.
* Интернет при первом запуске. Файл модели `models/hand_landmarker.task` скачивается автоматически.
* Windows, macOS или Linux.
* На macOS нужно разрешить терминалу или IDE доступ в разделе «Универсальный доступ», иначе PyAutoGUI не сможет двигать курсор.
* На Linux нужен рабочий сеанс X11. В некоторых окружениях Wayland управление мышью может быть ограничено.

## Запуск

```bash
python main.py
```

Перед первым запуском проверьте камеру в `config.json`:

* `camera.source` со значением `0` выбирает локальную веб-камеру.
* `camera.source` со строкой выбирает IP камеру, например `http://192.168.0.15:8080/video`.
* `camera.flip` включает зеркальное отображение кадра.

Что делать если нет камеры? На телефон можно скачать приложения по типу IP WebCam и т.п., в source ставим локальный IP, который он даёт.

Управление мышью при старте выключено. Нажмите `c` в окне камеры или удерживайте две открытые ладони две секунды.

## Жесты

* Указательный палец: курсор следует за рукой.
* Щипок большого и указательного пальцев: короткий щипок даёт левый клик, длинный запускает перетаскивание.
* Щипок большого и среднего пальцев: правый клик.
* Кулак: пауза, курсор остаётся на месте.
* Два пальца: прокрутка. Рука выше нулевой точки крутит вверх, рука ниже крутит вниз.
* Две руки: одна рука ведёт курсор, вторая управляет прокруткой.
* Кулак на три секунды: выключить управление.
* Две открытые ладони на две секунды: включить управление.

## Клавиши

* `c`: включить или выключить управление.
* `m`: перейти к следующему режиму.
* `p`: переключить точку, которая ведёт курсор.
* `q`: выйти из программы.

## Режимы

* `mouse`: основной режим управления курсором и кликами.
* `presentation`: взмах открытой ладонью вправо или влево нажимает стрелки для смены слайдов.
* `game`: щипок нажимает пробел, кулак удерживает стрелку вниз.

Список режимов и режим по умолчанию задаются в разделе `modes` файла `config.json`.

## Конфигурация

Все параметры находятся в `config.json`. При запуске файл дополняется значениями по умолчанию и проверяется. Неизвестные ключи выводят предупреждение, а некорректные значения дают понятную ошибку.

Основные разделы:

* `camera`: источник, размер кадра, частота и зеркалирование.
* `tracker`: путь к модели и пороги распознавания руки.
* `pointer`: точка, которая ведёт курсор, и минимальный шаг движения.
* `zone`: рабочая зона кадра, которая отображается на весь экран.
* `smoothing`: фильтр One Euro и параметры плавного довода курсора.
* `gestures`: пороги щипка, задержки, гистерезис и поведение кликов.
* `scroll`: чувствительность, инверсия и скорость прокрутки.
* `modes`: доступные режимы и режим по умолчанию.
* `controls`: горячие клавиши и показ панели.
* `safety`: стартовое состояние, защита PyAutoGUI и отступ от краёв экрана.
* `safety_switch`: включение и выключение управления жестами.
* `presentation`: клавиши смены слайдов и параметры взмаха.
* `game`: клавиши прыжка и приседания.
* `debug`: отрисовка скелета руки, зоны, FPS и времени распознавания.

Если прокрутка идёт не в ту сторону, установите `"invert": true` в разделе `scroll`. Если курсор движется слишком резко, увеличьте `glide_tau_seconds` и `one_euro_min_cutoff`.

## Тесты

Полный набор модульных тестов:

```bash
python -m unittest discover -s tests -v
```

Сквозная проверка без камеры и реальной мыши:

```bash
python tests/e2e_check.py
```

Ручная проверка прокрутки:

```bash
python scroll_test.py
```

Сквозная проверка подменяет камеру, время и PyAutoGUI, но использует настоящий `main.py`, настоящий конвейер и синтетическую руку. Она проверяет клики, перетаскивание, прокрутку, режимы, выключатель жестами и освобождение кнопок при выходе, потере руки и срабатывании защиты.

## Безопасность

* Управление выключено при старте, если в `safety.start_enabled` не указано иное.
* Курсор не доходит до краёв экрана, поэтому рука случайно не вызывает защиту PyAutoGUI.
* Отведите настоящую мышь в левый верхний угол, чтобы экстренно остановить программу.
* Все зажатые кнопки мыши и клавиши отпускаются при выключении управления, потере руки, смене режима, ошибке и выходе.
* Зажатая кнопка отпускается даже при сработавшей защите PyAutoGUI.

## Диагностика

Камера не открывается:

* Проверьте `camera.source`.
* Закройте программы, которые уже используют камеру.
* Разрешите доступ к камере в настройках системы.

Модель не скачивается:

* Проверьте интернет.
* Скачайте `hand_landmarker.task` вручную и положите файл в `models/hand_landmarker.task`.

Курсор не двигается на macOS:

* Разрешите доступ в разделе «Универсальный доступ» для терминала или IDE.
* Перезапустите терминал после изменения разрешения.

Жесты срабатывают слишком часто или слишком редко:

* Настройте `gestures.pinch_on`, `gestures.pinch_off` и `gestures.pinch_confirm_frames`.
* Проверьте освещение и держите ладонь полностью в кадре.
